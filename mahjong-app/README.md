# 🀄 你的专属麻将日记

记录她的每一局麻将，给她满满的情绪价值。

## 功能

- 📝 **记一局** — 赢了/输了、金额、心情 emoji、备注
- 🎭 **情绪引擎** — 20+ 场景自动生成温暖文案，赢了拼命夸，输了使劲哄
- 🏅 **里程碑庆祝** — 首胜、连胜、总盈亏突破，弹窗庆祝
- 📖 **日记风格历史** — 根据心情+输赢自动生成日记故事
- 📊 **周总结 / 月总结** — 数据 + 情绪点评
- 📈 **走势柱状图** — 最近 20 局可视化
- ⏰ **约局提醒** — 桌面通知提醒

## 使用

直接双击 `index.html` 用浏览器打开即可，数据存在浏览器本地。
